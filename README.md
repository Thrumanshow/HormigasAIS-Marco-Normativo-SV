# HormigasAIS · Marco Normativo (El Salvador)

Índice de fuentes públicas y notas del autor sobre disposiciones salvadoreñas potencialmente relevantes para la infraestructura, los protocolos (LBH) y el software de HormigasAIS.

> **Alcance:** este repositorio es un índice de fuentes y un mapa de notas del autor. No constituye asesoría legal, certificación ni validación por parte de una autoridad pública. La inclusión de una norma no determina por sí sola que aplique al proyecto ni que este la cumpla.

## Delimitación documental

- **Fecha de revisión documental:** 29 de octubre de 2026. Esta fecha no equivale a una certificación de vigencia normativa ni a una revisión exhaustiva de todas las reformas.
- **Criterio de selección:** se incluyen instrumentos que podrían ser relevantes para software, IA, ciberseguridad, datos personales o incentivos tecnológicos en El Salvador. La aplicabilidad a HormigasAIS debe analizarse por separado.
- **Trazabilidad:** `FUENTES.md` identifica referencias normativas y `evidencias/` contiene snapshots técnicos. Un código HTTP 200 solo registra una respuesta observada; un hash identifica determinados bytes en una ejecución. Ninguno de esos elementos, por sí solo, acredita vigencia, autenticidad oficial, cumplimiento legal o revisión independiente.
- **Gobernanza:** el enlace a `GOVERNANCE.md` apunta a un archivo del repositorio relacionado `HormigasAIS`, no a un archivo de este repositorio.

## Contenido

- **`FUENTES.md`:** leyes, decretos, resoluciones y enlaces de consulta.
- **`MATRIZ.md`:** lectura del autor sobre requisitos, estados, evidencia disponible y pendientes.
- **`CHANGELOG.md`:** historial de cambios documentales.
- **`scripts/snapshot.sh`:** consulta fuentes y metadatos públicos y escribe un archivo de snapshot; revisar el código antes de ejecutarlo.
- **`evidencias/`:** registros técnicos versionados. No son inmutables y no constituyen certificaciones.
