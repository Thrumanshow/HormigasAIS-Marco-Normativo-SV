# HormigasAIS · Marco Normativo (El Salvador)

Índice de las leyes salvadoreñas relevantes para el ecosistema HormigasAIS, con enlaces a las fuentes oficiales y una matriz que indica el estado y la evidencia de cada requisito.

> **Aviso:** este repositorio es un índice de fuentes y notas del autor. No es asesoría legal, ni una certificación, ni una validación por parte de ninguna autoridad. Cada afirmación sobre el proyecto indica su estado y su evidencia.
